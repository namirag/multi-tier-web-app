# Multi-Tier Web Application with Docker & AWS

## Project Overview

This project is a multi-tier web application built using a modern cloud architecture.  
The application contains a frontend, backend API, and MySQL database running through Docker containers.

The project demonstrates containerization, backend development, database integration, and cloud deployment using AWS EC2.

---

## Architecture

User
|
↓
Frontend (HTML + JavaScript + Nginx)
|
↓
Backend API (Python Flask)
|
↓
MySQL Database


---

## Technologies Used

### Frontend
- HTML5
- JavaScript
- Nginx

### Backend
- Python
- Flask REST API
- MySQL Connector

### Database
- MySQL 8

### DevOps & Cloud
- Docker
- Docker Compose
- Git & GitHub
- AWS EC2
